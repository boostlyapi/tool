# tool

tool — CLI на Go для работы с Apache Kafka через JSON. Помогает отправлять и читать сообщения, проверять состояние топиков и управлять смещениями consumer groups из терминала и shell-скриптов.

## Возможности

- Чтение сообщений из выбранных партиций в заданном диапазоне смещений или в режиме ожидания новых сообщений.
- Отправка обычного текста и JSON-объектов с указанием ключа, значения и партиции; поддержка base64 и hex для бинарных данных.
- Просмотр топиков, партиций, их смещений и лидеров.
- Просмотр смещений и отставания consumer groups, сброс или ручная установка смещений.
- Создание и удаление топиков.
- JSON-вывод для обработки через `jq`, настройка подключения через переменные окружения и поддержка TLS-аутентификации.

## Установка

Понадобится Go. Из корня исходников соберите исполняемый файл:

```sh
go build -o tool .
./tool -help
```

При необходимости поместите его в каталог из `PATH`:

```sh
mkdir -p "$HOME/.local/bin"
cp tool "$HOME/.local/bin/tool"
export PATH="$HOME/.local/bin:$PATH"
```

Для работы команд нужен доступ к брокеру Kafka.

## Использование

В примерах ниже брокер доступен по адресу `localhost:9092`, а топик `events` уже создан.

Отправить сообщение с ключом в партицию 0:

```sh
printf '%s\n' '{"key":"order-42","value":"created","partition":0}' \
  | tool produce -brokers localhost:9092 -topic events
```

Прочитать сообщения из партиции 0 со смещениями от 0 до 10:

```sh
tool consume -brokers localhost:9092 -topic events -offsets '0=0:10'
```

Следить за новыми сообщениями во всех партициях, начиная с последнего доступного сообщения:

```sh
tool consume -brokers localhost:9092 -topic events -offsets 'all=newest-1:'
```

Посмотреть сведения о топиках, подходящих под регулярное выражение:

```sh
tool topic -brokers localhost:9092 -filter '^events$' -partitions
```

Проверить смещение и отставание группы для партиции 0:

```sh
tool group -brokers localhost:9092 -group workers -topic events -partitions 0
```

Установить смещение этой группы в 1:

```sh
tool group -brokers localhost:9092 -group workers -topic events -partitions 0 -reset 1
```

Изменение смещений влияет на то, какие сообщения группа прочитает при следующем запуске. Перед сбросом проверьте выбранные группу, топик и партицию.

Справка по командам:

```sh
tool -help
tool consume -help
tool produce -help
tool admin -help
```
